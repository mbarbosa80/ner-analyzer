NER Spatial Coverage Analyzer · version 5.1.1 · Windows · macOS

Quick install

One page. Five minutes, no internet, nothing to install first — Python comes inside the package. The full installation manual (docs\INSTALL.html) covers backups, updates, another port, uninstalling and every message the installer can print.

What you need

  • Windows 10 or 11, 64-bit, with about 1 GB of free disk.
  • Administrator rights are not required. With them, run setup.bat; without them (a managed computer where IT will not grant them), run setup-noadmin.bat instead — the application installs for your account only, in your own profile, and nothing is written outside it. If IT offers to type an administrator's password for you, decline: the application would be installed into their profile, and the installer refuses it.
  • A current Google Chrome, Microsoft Edge or Mozilla Firefox.
  • The file ner-analyzer-5.1.1-windows.zip (about 100 MB), downloaded from the link you were sent.

Install it

  1. Unblock the zip (optional, saves a Windows warning): right-click ner-analyzer-5.1.1-windows.zip → Properties → tick Unblock → OK.
  2. Unzip it: right-click → Extract All…. Your Downloads folder is fine — nothing stays there. Do not run anything from inside the zip.
  3. Open the ner-analyzer folder. With administrator rights: right-click setup.bat → Run as administrator → Yes (a plain double-click also works: it asks Windows for the rights itself). Without them: double-click setup-noadmin.bat. A black window runs through six numbered steps, two to five minutes.
  4. Your browser opens at http://127.0.0.1:8000 and an NER Analyzer shortcut appears on the desktop. Create the first account — username, name, a password of at least 10 characters. There is no default user or password; the first account is the administrator.
  5. Back in the black window, press any key. It closes and, a few seconds later, deletes the unzipped folder and the zip. Only the application is left, running.
Where it went

C:\Users\<you>\AppData\Local\Programs\ner-analyzer. It starts by itself every time you sign in to Windows, with no window; a watchdog restarts it within two minutes if it ever stops. From now on, open it with the desktop shortcut or by typing 127.0.0.1:8000 into the browser. The application runs only on your computer and makes no connection to the internet.

On a Mac

For a MacBook with an Apple Silicon processor (M1 or later — Apple menu → About This Mac says Chip Apple M…), macOS 11 or later, about 1 GB free. No administrator password is needed. The file is ner-analyzer-5.1.1-macos-arm64.zip (about 110 MB).

  1. Unzip it: double-click the zip in Downloads. A ner-analyzer folder appears (sometimes inside a folder with the zip's name).
  2. Open Terminal (Spotlight: ⌘+Space, type Terminal). Type bash and a space, drag setup.command from the ner-analyzer folder into the Terminal window, and press Return. Six numbered steps follow, one to three minutes.
  3. Your browser opens at http://127.0.0.1:8000 and an NER Analyzer link appears on the Desktop. Create the first account, as above.
  4. Press Return in Terminal and close it. The unzipped folder and the zip are already gone.
Where it went

~/Applications/ner-analyzer (your home folder → Applications). It starts by itself when you sign in to the Mac and again if it ever stops. Its mac folder holds stop, start, backup and uninstall. Updating is the same four steps with the new zip: the data is backed up and kept. Double-clicking setup.command also works, but macOS answers Apple could not verify… the first time: click Done, then System Settings → Privacy & Security → Open Anyway. The Terminal way above avoids that.

Update to a new version

Exactly the same five steps with the new zip. The installer recognises the installed version, backs up its database, keeps every project, account and drawing, and replaces the program files. Press Ctrl+Shift+R once in the browser afterwards. The version you replaced is kept next to the new one as ner-analyzer.previous until the next update; delete it once the new version works. No administrator rights are needed for an update either: setup-noadmin.bat (or setup.command on a Mac) installs over the old version for your account and keeps every project.

If something goes wrong

You seeDo this
Open File – Security Warning / SmartScreenClick More info → Run anyway (or Run). The scripts are plain text — open them in Notepad if you want to read them.
The administrator rights were not grantedThe Windows prompt was answered No, or your account cannot get them. The window then asks Install without administrator rights, for this account only? [Y/N] — answer Y. Or close it and double-click setup-noadmin.bat.
This window runs as another account than the person signed inSomeone typed another account's password into the prompt. Get the rights on your account, sign in as yourself, run it again.
The browser says the site cannot be reachedThe server is still starting (20 to 40 seconds after a sign-in). Wait and reload.
An amber pill in the top bar, or a blank pageThe browser kept an old copy of the interface: Ctrl+Shift+R.
Mac: this Mac has an Intel processorThis package is for Apple Silicon (M1 or later). An Intel Mac needs another package — ask Marcelo.
Mac: Operation not permitted or nothing happensA managed Mac (company profile) may block scripts from Downloads. Move the unzipped ner-analyzer folder to your Desktop and repeat step 2; if it still refuses, IT has to allow it.
Forgot your passwordAsk the administrator to use Reset password in the app. If there is none, or it is you: in the installed folder, double-click reset-password.bat (Mac: mac/reset-password.command), choose the account and type the new password twice.
Anything elseRead the message in the black window — it says what stopped and nothing was changed — then check Common problems in docs\INSTALL.html inside the installed folder, or send a screenshot of the window to Marcelo.
