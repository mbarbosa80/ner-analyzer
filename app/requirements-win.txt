# NER Spatial Coverage Analyzer - Windows runtime
#
# This is requirements.txt with one deliberate difference: it asks for plain
# `uvicorn` plus the Windows-compatible half of its `[standard]` extra, instead
# of `uvicorn[standard]`.
#
# The reason is that `[standard]` pulls in uvloop, which has no Windows build.
# On a normal install pip evaluates the marker and skips it; when the packages
# are downloaded for another machine (`pip download --platform win_amd64`) that
# marker cannot be evaluated and the resolution fails outright. Listing the
# working parts explicitly is what makes an offline Windows bundle possible.
#
# The application itself is identical either way - uvloop is a speed-up on
# Linux, not a feature.
